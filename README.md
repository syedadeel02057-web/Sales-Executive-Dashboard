# Task 2: Data Visualization & Storytelling - Superstore Dashboard

## Overview
This repository contains Task 2 for the Elevate Labs Data Analyst Internship. The goal is to transform raw sales data (`train.csv`) into an executive visual dashboard that highlights business trends.

## Insights
* **Total Revenue:** $2,261,536.78 generated across 4,922 unique orders.
* **Top Region:** The **West** region leads overall sales at 31.4% ($710.2K), followed by the **East** region at 29.6% ($669.5K).
* **Top Product Category:** **Technology** generates the highest revenue ($827.5K), driven heavily by *Phones* ($327.8K) and *Machines* ($189.2K).
* **Customer Segment:** **Consumer** accounts drive 50.8% ($1.15M) of overall sales volume.

## Repository Files
* `train.csv` - Raw sales dataset
